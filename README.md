# dsh-knowledge · 知识库插件

DSH 左侧栏「知识库」入口：把本地 Obsidian 库、项目文件夹和收藏同步进来的帖子建成索引。可以边打字边看原文，也可以让 AI 读完相关资料再回答，回答里每句结论都标出处。

## 界面（0.3.0）

- **首页**：每次打开换一句诗文（中外诗词、哲学；外文附译文），会按情况挑主题：刚收进新东西、刚聊得很深、夜里。输入框边打字边出原文片段；按 ↵ 让 AI 回答，⇧↵ 换行，↑↓ 选原文后 ↵ 直接打开。文件夹按钮可以把范围限定在某几个数据源。
- **问答**：AI 先把问题拆成检索词去翻，判断资料够不够，不够就换个说法再翻（最多 3 轮），再流式写出回答。来自资料的结论带 [n] 角标，悬停对应右侧参考资料，点开就是原文；资料里没有的内容单独放在「一般经验」框里。话题存在 `~/.dsh/knowledge/chats/`，一个话题一个 JSON 文件。模型用 DSH 当前默认模型，拆词和判断这两步用同一家的快速模式。
- **浏览**：玻璃文件夹，打开时纸张从文件夹口铺到桌面上；左侧目录树；S / M / L 三种大小（⌘− / ⌘+）。最上面一行是「刚收进来」。
- **数据源**：系统的选择窗口添加文件夹，扫描时文件夹会翻动并计数；移除后 5 秒内可以撤销。
- **阅读**：原文按 Markdown 排版，命中的那段高亮；可复制路径、在 Finder 中显示、引用到对话。
- **带到对话 / 引用到对话**：内容先复制到剪贴板；对话输入框在页面上就直接放进去，不在就等你切回对话时自动放进去（两分钟内有效）。
- 日夜跟随 DSH；输入框用和 Dune 一样的彗星光标（颜色、粗细读 Dune 的设置）；系统开了「减少动态效果」时动效全部收短。
- 界面跑在 Shadow DOM 里，样式和 DSH、其他插件互不影响。

## 索引

- **数据源管理**：添加任意文件夹（自动识别 Obsidian 库）、移除、单独扫描。
- **增量扫描**：SHA-256 指纹，只重算变更文件；自动删除已消失文件；启动后 1.5 秒自动扫一次。
- **文件夹监听**（0.2.0）：新增 / 修改 / 删除 / 改名约 1.5 秒后自动入库；每 10 分钟定时对账兜底。数据源文件夹暂时不在时只停监听、不清索引，30 秒后自动重试。
- **中文友好切块**：按 CJK 占比插值（中文 560 字 / 重叠 80，英文 1500 / 200），每块带 Markdown 标题前缀与行号。
- **检索**（0.3.0）：多词模糊检索。问句先去掉「怎么」「什么」这类虚词，再按词和二字片段召回打分；整词命中、标题命中加分，作废版本降权；每篇最多 2 段。
- **已作废标记**：路径含 `90_历史版本` / `_旧版_` / `作废` / `trash/` 的文档标 `superseded`。
- **Agent 工具**：`kb_search`（会话里直接查，返回带锚点的 markdown）。
- **只读**：对源文件零写入。

## 数据与配置

- 索引库：`~/.dsh/knowledge/kb.db`（SQLite + FTS5，WAL）
- 配置：`~/.dsh/knowledge/config.json`（首次修改数据源时生成）；每个数据源可以加 `color`（如 `"#7B61FF"`）和 `sym`（`note` `gear` `mark` `people` `book` `box` `down` `dot`）自定义文件夹的颜色和符号
- 问答话题：`~/.dsh/knowledge/chats/*.json`

## 排除规则

默认忽略：`.git`、`node_modules`、`.obsidian`、`.trash`、`trash`、`tmp`、`.DS_Store`、`__pycache__`、`.idea`。
单源最多 5000 个文件。二进制（pptx/xlsx/docx/pdf/图片）本版本不索引。

## HTTP API（面板使用）

`/knowledge/api/` 下：`status` · `search` (POST) · `recent` · `docs?src=` · `raw?id=` · `tree` · `doc?rel=` · `scan` (POST) · `sources` (POST) · `pick-folder` (POST) · `reveal` (POST) · `chats` · `chat?id=` · `chat` (POST，NDJSON 流) · `chat-delete` (POST)
